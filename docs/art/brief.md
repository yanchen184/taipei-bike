# 美術需求單：台北街景寫實貼圖

## 共通規格

- 風格：寫實照片質感的台北老城區，白天陰天的均勻光（不能有明顯的單向陰影或高光，光影由 3D 場景負責）。
- 視角：正投影、正對表面，沒有透視、沒有暈影。
- 不得出現任何文字、數字、招牌字、浮水印、人物、車輛。招牌文字由程式另外畫。
- 格式：JPEG（品質 85）、sRGB、8-bit RGB。
- 標示「無縫」的圖，四邊要能左右、上下接續平鋪，看不出接縫。
- 存放路徑：`src/assets/textures/<檔名>.jpg`。

## 立面窗位（facade-apartment 與 facade-apartment-ac 必須遵守）

程式會依這個位置畫夜間亮燈的遮罩，窗戶偏掉就會錯位。

- 圖寬 768，平分三格，每格 256 px。
- 第 k 扇窗（k = 0, 1, 2）的玻璃矩形：x 從 `k×256 + 28` 到 `k×256 + 228`，y 從 56 到 296。
- 鐵窗可以比玻璃矩形外擴最多 8 px。
- 圖的最下方 y 352–384 是樓板水泥線與牆面，不放窗。

## 驗收

- 檔名、尺寸、無縫方向都跟清單一致（用程式讀 JPEG 的 SOF 區段檢查尺寸）。
- 全部檔案加起來不超過 1 MB。
- 立面圖的三個玻璃矩形內部明顯比牆面暗，矩形外的牆面不得有窗。
- 人工目視檢查：沒有文字、浮水印、人物、車輛。
